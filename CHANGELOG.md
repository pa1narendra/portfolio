# Changelog

## 1.0.0 — 2026-07-10

First version.

- Light lavender field with drifting pastel washes and a liquid cursor trail: the background bends smoothly along the pointer's path and stirs gently on scroll (analytic gaussian displacement in a WebGL shader, no simulation grid).
- Boot sequence with a counting loader and an anime Einstein who waves hello, then vanishes with the split shutters.
- Cinematic hero: pinned headline that disassembles letter by letter under scroll scrub (GSAP ScrollTrigger), live status strip with a real ticking IST clock.
- Horizontal project gallery: vertical scroll drives a pinned journey through three floating tablet frames (Framer Motion spring tilt), each carrying a live, playable demo of the actual product — a 3D chess knight with legal-move highlighting (Chessing), a cursor-reactive voice waveform with a self-typing interview (Mockstar), and an SMS-to-ledger machine with a running total (MoneyCap).
- Velocity-reactive marquee, split-word masked headings, per-panel copy parallax, accent progress rail.
- Living sections: the work log replays itself as an animated git history; principles run as a passing test suite; contact is a working mail terminal that opens the visitor's mail app pre-filled.
- Reduced-motion support throughout, demos pause off-screen, mobile fallbacks for pinned sections.
